# Security and public-data boundary

This repository can process prepared planning material. Keep public inputs public-safe.

Do not commit:

- passwords, tokens, private keys, or `.env` values
- customer or personal data
- private hostnames or IPs
- production IDs
- complete internal service maps
- private runtime configuration

Planning output is not a security approval and is not runtime truth.

If a security issue concerns the tool itself, use GitHub private vulnerability reporting where available instead of publishing sensitive details in an issue.
